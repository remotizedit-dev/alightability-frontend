# **App Name**: Alight Ability

## Core Features:

- Home Page: Landing page with an overview of the company's mission and services.
- About Us: Detailed information about the company's history, values, and team.
- Our Services: Comprehensive listing and description of all clinical services offered.
- Contact Us: A contact form and company contact information for inquiries and support.
- Join Us: A page listing open positions and information about career opportunities within the company.
- Privacy Policy: Detailed page outlining the company's privacy policy and data handling practices.
- Responsive Navbar: A responsive navigation bar that adapts to different screen sizes, ensuring easy navigation on all devices with smooth scrolling animation and fade-in effects.

## Style Guidelines:

- Primary color: A calm blue (#5DADE2) to evoke trust and professionalism.
- Background color: White (#FFFFFF) for a clean and modern look.
- Accent color: Soft pink (#F7D5E5) for highlighting important sections.
- Body text: 'PT Sans', a modern sans-serif, provides clarity and approachability.
- Headline text: 'Space Grotesk' as the headline font provides a modern feel to the landing pages.
- Use clean, professional icons to represent different clinical services. Prefer a thin line style.
- A clean and modern layout with clear sections for easy readability.
- Subtle fade-in animations for content sections and smooth scrolling for navigation.
